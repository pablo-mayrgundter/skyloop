# Infographic site

Standalone copies of the four infographic pages, generated by `build.py` from their sources:

| Page | Source | Also on claude.ai |
|---|---|---|
| [index.html](index.html) (overview) | `overview/index.html` | <https://claude.ai/artifact/E75ZQx2eW1CXWKeJgPk6gi> |
| [boomshield.html](boomshield.html) | `boom-shield/infographic/index.html` | <https://claude.ai/artifact/1GASTWSYperFtVLyLY29VJ> |
| [skyloop.html](skyloop.html) | `skyloop-review/infographic/index.html` | <https://claude.ai/artifact/Rvmp18jJLdP7pAPWvuiHHK> |
| [hyperloop.html](hyperloop.html) | `hyperloop/infographic/index.html` | <https://claude.ai/artifact/QbRskhNLJEzpye6SzGC3fB> |

`assets/` holds full-page screenshots (light/dark, 1280 and 400 px; `-v0.1` for earlier-version tabs).

- **Rebuild:** `python site/build.py` from the repo root after editing a source page; commit both.
- **View locally:** `python -m http.server -d site` and open <http://localhost:8000>.
- **Hosting:** `.github/workflows/pages.yml` deploys this folder to GitHub Pages on every push to `main` once Pages is set to "GitHub Actions" in the repo settings.
